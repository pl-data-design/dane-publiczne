# Dane publiczne: legislacja i nabory

Automatyczny zbiór publicznych danych:
- nowe akty z Dziennika Ustaw i Monitora Polskiego,
- nowe druki sejmowe i etapy procesów legislacyjnych,
- harmonogramy naborów programów regionalnych Funduszy Europejskich.

Źródła: oficjalne API Sejmu (api.sejm.gov.pl, ELI) oraz strony instytucji zarządzających programami regionalnymi. Strony, które w pliku robots.txt blokują automatyczne pobieranie, są pomijane.

Wyniki: katalog `dane/`, spis treści w `dane/index.json`.
